# PhD Listening Examples

Supplementary musical excerpts organised by thesis chapter and excerpt number.

## Layout

- `index.html` — independent site navigation homepage
- `assets/site.css` — shared visual styling
- `chapter-01/excerpt-01/`
- `chapter-05/excerpt-01/`
- `chapter-05/excerpt-02/`
- `chapter-05/excerpt-03/`
- `chapter-06/excerpt-01/`
- `chapter-06/excerpt-02/`

Each excerpt folder contains an `index.html` placeholder and `audio/` and `images/` directories. The `.gitkeep` files only keep those directories visible in GitHub.

## Adding excerpts

1. Add the audio (e.g., `audio/excerpt.mp3`) and score images (e.g., `images/page-1.png`) to the relevant excerpt's folder.
2. Replace *only that excerpt's* `index.html` placeholder with its audio player and score viewer. Keep links to assets relative to that excerpt, e.g. `audio/excerpt.mp3`.
3. Change the excerpt's homepage status from “Not yet uploaded” to the appropriate label and update details where needed.
4. Use the stable URL `https://hao-1995.github.io/phd-listening-examples/chapter-01/excerpt-01/` for references.

## Existing test

The original Gao Ping proof-of-concept files remain in `phd-listening-examples-ready/`. They are **not** used as the basis of the newly created navigation homepage.

Before publishing copyrighted audio and score images, ensure that public online distribution is authorised.
