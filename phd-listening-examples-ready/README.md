# PhD Listening Examples

Supplementary audio and notation for a doctoral research project on intercultural listening in contemporary art music.

## Test excerpt

- Composer and work: Gao Ping, *Si Bu Xiang*
- Excerpt: bars 70–83, 1:50–2:06
- Audio: `audio/gao-a1.mp3`
- Score pages: `images/gao-bars70-79-page1.png`, `images/gao-bars80-83-page2.png`
- Web page: `index.html`

## Publishing with GitHub Pages

1. Create a **public** repository named `phd-listening-examples`.
2. Upload the files and folders from this ZIP to the **root** of the default branch. Do not upload the ZIP itself as the website.
3. In **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/(root)`, then save.
4. After publishing, the URL should be `https://Hao-1995.github.io/phd-listening-examples/` if the username and repository name remain unchanged.

The repository must contain these paths at its root:

```
index.html
.nojekyll
README.md
audio/gao-a1.mp3
images/gao-bars70-79-page1.png
images/gao-bars80-83-page2.png
```

Publication makes the media available to the public; confirm that you have permission to share the recording and score images before deploying.
